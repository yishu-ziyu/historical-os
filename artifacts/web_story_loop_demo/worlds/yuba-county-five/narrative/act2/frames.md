# Act 2: Abandonment & Search

## frame-201: 发现弃车

**视觉**: 雪地中的灰色车身，车头灯照出一片模糊的白色。雪地上有一串脚印，通向森林深处。

**sigma**: 0.20

```
【档案页 FRAME-201 · 1978-02-28 11:00 UTC-8】

地点: 普卢默斯国家森林，Yuba County 51A 公路（封路道路）
事件: 加州巡警发现 1969 年墨丘利蒙特哥，车牌 187DLT

车辆状态:
- 发动机: 可以启动
- 轮胎: 气压正常
- 油箱: 约 1/3 满（约 15-20 加仑）
- 钥匙: 在点火器中
- 车内温度: 约 0°C（环境温度约 -3°C）
- 后备箱: 一个购物袋（内有 3 罐金枪鱼、2 罐豆类、2 罐水果），一床毯子，一个手电筒

车辆周围:
- 车旁雪地上有多组脚印，均向南延伸至森林深处
- 脚印深度表明为轻装上阵（无背包）
- 鞋印尺寸: 4组（男性鞋印），1组（较小，可能是女性鞋印 -- 未记录）
- 脚印在约 1.6 公里处开始消失（被风吹平）
- 脚印方向: 持续向南

未记录内容:
- 为什么弃车时钥匙在点火器里
- 为什么只带了车内已有的食物（没有从家中带任何补给）
- 脚印是否在一段时间内被重新覆盖
- 发现车辆时是否有最近的轮胎痕迹
- 那条封路道路的路障是否被移动
- 车辆被发现前已有多少天无人靠近
- 车内是否有指纹、毛发、纤维证据
- 发现者是否接触了车内物品
```

**关键矛盾**: 车完全正常。弃车的动机不明。

## frame-203: 乔·肖恩斯的证词

**视觉**: 一个穿着厚重外套的老人，在雪中艰难行走。他滑倒了。远处模糊的人影。他的脸被风雪覆盖。

**sigma**: 0.45

```
【档案页 FRAME-203 · 1978-03-05（乔·肖恩斯的首次正式陈述）】

时间: 1978-03-05
地点: 普卢默斯国家森林，距弃车点约 4 公里
陈述人: 乔·肖恩斯，67岁，退休农夫，埃尔多拉多县

陈述内容:
- 当时我正在雪中行走，大约在 [时间不记得]
- 我看到前方有大约五到七个人
- 其中一个穿着白色外套，其他人穿着深色衣服
- 有一个女人，她抱着一个婴儿
- 其中一人走向我，帮助我站起来
- 他问我有没有事，然后就离开了
- 他们向南走了

后续修正:
- 在后续询问中，肖恩斯说他当时"有些头晕"
- 草药医生（当地行医者）称检查出他体内有酒精
- 肖恩斯坚称他没有喝酒
- 肖恩斯声称"那些人不像是尸体" -- 他们看起来"活生生的"

法医评估:
- 四具尸体被发现时均已高度腐烂（约3个月后）
- 三具为白骨化或部分白骨化
- 一具（韦尔）被毛毯包裹，但可见明显脱水
- 肖恩斯陈述中的"女人抱着婴儿" -- 无任何证据支持
- 肖恩斯陈述中的"帮助他站起来的人" -- 无法确认身份

未记录内容:
- 肖恩斯在陈述前的确切活动
- 他声称的"头晕"是否有药物原因
- 草药医生的检查报告是否保留
- 为何在距弃车点 4 公里处（而非弃车点附近）
- 他是否看到了脚印或车辙
- 他的证词是否与其他搜救队成员的观察一致
```

**关键矛盾**: 他看到的人是谁？如果那些"活生生的人"是五人，那泰德为什么三个月后才被发现，已经腐烂了？

## frame-204: 第一个冬天过去了

**视觉**: 空镜头。普卢默斯国家森林在春天。雪开始融化。树影变长。一辆黑色的车在公路上行驶，车窗反射着阳光。

**sigma**: 0.50

```
【档案页 FRAME-204 · 1978-06-17】

时间: 1978年6月中旬
事件: 季节性工人发现美国林务局拖车（编号 FE36），门从内反锁
地点: 距弃车点约 32 公里（步行距离）

拖车内部:
- 房间大小约 12×12 平方英尺
- 丙烷炉（有燃料，可以点火）
- 木柴堆（约 20 块）
- 毛毯 3 条
- 罐头食品 12 罐（未开封）
- 睡袋 1 个
- 个人物品若干

发现者:
- 当地木材公司季节工，在清理一条伐木道路时接近拖车
- 注意到门口有异常的气味
- 敲门无人应答
- 撬开门后发现内部情况

尸体:
1. 泰德·韦尔: 在卧室区域，被毛毯包裹，部分骨架化。周围有：
   - 两罐未开封的罐头（在他伸手可及处）
   - 毛毯（已使用）
   - 一具皮质钱包（内有约 $16）
   - 手镯（他生前佩戴的）
   - 死亡原因: 推测为饥饿 + 脱水 + 可能的哮喘发作
   - 关键: 周围有足够的食物和水（雪可以化为水），有热源
   - 他不是冻死的。他不是饿到动不了的。他有机会活下去。

2. 杰克·休伊特: 距拖车约 1.6 公里，仅剩一只鞋和部分下颌骨
   - 鞋带系好
   - 鞋内无脚
   - 周围无其他遗骸

3. 比尔·斯特林: 距拖车约 3.2 公里，仅剩部分鞋子和少量衣物碎片
   - 骨密度分析表明死亡时间与韦尔相近

4. 杰克·马德鲁加: 距拖车约 5.6 公里，在溪流附近
   - 部分遗骸

未发现:
- 加里·马蒂亚斯: 无任何遗骸
- 其他任何人的遗骸
- 第五个人的鞋子/衣物
- 乔·肖恩斯看到的"女人和婴儿"的证据
- 那枚在拖车附近发现的不属于任何受害者的手表
- 任何武器
- 任何不属于五人的指纹（拖车内仅发现了四人的指纹）

未记录内容:
- 季节性工人是否保留了完整的发现时间线
- 拖车的门锁是否被从内部破坏
- 门反锁的方式（从内挂上的锁链？还是其他机制？）
- 泰德的手腕上为什么有一条撕破的袖子（可能是用来撬门？）
- 季节性工人是否在发现后移动了任何物品
- 拖车在1978年冬季是否有人使用过的痕迹
- 丙烷炉是否有被使用过的迹象
- 木柴是否有燃烧过的迹象
```

**关键矛盾**: 四具尸体分散在32公里的范围内。泰德在有食物有火的地方饿死。加里从未出现。

## frame-205: 手表

**视觉**: 一只手表的特写。表盘碎裂。指针停在 3:17。淡水锈蚀渗透了表壳的缝隙。镜头拉远 -- 它在雪地里，无人认领。

**sigma**: 0.75

```
【档案页 FRAME-205 · 手表物证记录】

物品: 男式机械手表，品牌不清晰（表面磨损严重）
位置: 拖车 FE36 东南方约 200 米处，雪地中
发现时间: 1978年6月（与尸体同时）

鉴定结果:
- 机芯内有淡水锈蚀（与当地溪水矿物质匹配）
- 表壳为铜合金，有明显的长期暴露痕迹
- 表面玻璃碎裂
- 指针停在 3:17
- 表带为皮革，已严重风化

关键问题:
- 这块手表不属于任何四位死者
- 受害者亲属确认五人中无人佩戴类似手表
- 那块手表在雪地里躺了整个冬天 -- 它属于谁？
- 谁在 3:17 做了什么？
- 这块手表与拖车的关系是什么 -- 掉落的？被放在那里的？

档案缝隙: 手表从未被追踪到来源
```

**关键矛盾**: 第五个人的痕迹 -- 但不是加里。加里不戴手表（据其母亲证实）。这块手表属于谁？

## frame-206: 拖车门

**视觉**: 拖车的门。从内部看，一条生锈的锁链挂在门框上。门板的磨损方式表明它被反复推拉过。外面是白茫茫的雪地。

**sigma**: 1.10

```
【档案页 FRAME-206 · 拖车门锁分析】

拖车 FE36 的入口门有一个特点: 当门从内部关闭时，一条挂链会自动扣上，将门从内侧锁住。

泰德·韦尔的尸体被发现时，挂链处于扣上状态。

可能的场景:
A. 泰德从内部扣上门链，然后无法打开（体力不支/失去意识）
B. 有人从外部将门锁上，但那人没有钥匙
C. 有人从外部将门锁上，然后从窗户离开
D. 锁链不是被扣上的 -- 是自然垂下的，但因尸体位置看起来像"锁上"

物证矛盾:
- 泰德的手腕处有一条撕破的袖子纤维 -- 可能是用袖子撬锁链
- 但他失败了，或者选择了放弃
- 如果他尝试过撬锁链，说明他想出去
- 如果他没尝试，说明他不想出去，或者他无法行动

档案缝隙: 门锁分析报告是否完整？拉链纤维是否与其他物证匹配？
```

**关键矛盾**: 门从内反锁 -- 但这是谁锁的？为什么锁？
