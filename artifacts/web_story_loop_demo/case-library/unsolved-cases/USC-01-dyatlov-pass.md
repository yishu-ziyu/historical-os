# USC-01 迪亚特洛夫事件 / Dyatlov Pass Incident

> 档案编号 GKV-DYATLOV-1959
> 分类: 悬案 / 集体死亡
> 时间: 1959年2月2日 - 2月28日
> 地点: 苏联乌拉尔山脉北部，Kholat Syakhl ("死亡之山")，海拔 1200m
> 官方密级: СОВЕРШЕННО СЕКРЕТНО (完全机密) — 1990年部分解密

---

## 案件概要

1959年1月23日，10名乌拉尔工业学院学生和毕业生从斯维尔德洛夫斯克（今叶卡捷琳堡）出发，开始一场为期14天的冬季滑雪登山探险。1月28日，队员尤里·尤丁因膝盖风湿病中途折返。其余9人继续前进。

他们再也没有回来。

2月20日，搜救队发现了他们的帐篷 -- 从**内部**被割开，队员的鞋、食物、保暖衣物全部留在里面。9具尸体在接下来的几周内陆续被发现，分布在距离帐篷1.5公里的范围内。部分尸体有严重内伤（肋骨骨折力度相当于汽车撞击、颅骨碎裂），但衣物上没有搏斗痕迹。部分死者的衣服上检测出**放射性物质**。

苏联调查持续了三个月，最终结论是"一种极强大的未知力量"导致了死亡。所有文件被列为最高机密。

2020年，俄罗斯官方重启调查，归咎于雪崩与极端低温 -- 但公众不接受这个结论。

## 尸体发现详情

**第一组 (5具，距帐篷最近)**:
- 帐篷和森林之间呈一列纵队 -- 看起来是在试图返回帐篷
- 三具穿着内衣，两具穿着单薄衣物
- 鞋和保暖外套全部留在帐篷内
- 死因: 体温过低

**第二组 (2具，火堆旁)**:
- 赤身裸体，衣服被剪下供给第一组的人穿
- 手上没有打斗伤痕
- 树叶和树枝做成的"简陋床铺"
- 死因: 体温过低

**第三组 (4具，最远，河涧中)**:
- 多人有严重钝器外伤（颅骨碎裂、肋骨骨折）
- 一名女性队员舌头**完全消失**
- 一名男性队员眼睛被剜去
- 衣服上检测出放射性物质
- 死因: 严重外伤 + 体温过低

## 不可解释的细节

1. **帐篷从内部割开**: 如果他们在极度恐慌中逃跑，割帐篷应该是从外向内 -- 但他们是从内割开的。这意味着他们"选择"离开，而非被迫离开。
2. **赤脚走零下30度的雪**: 即使极度恐慌，人也不会赤脚冲出帐篷。除非他们"无法穿上鞋"。
3. **放射性**: 衣服上的放射性物质来源不明。是后来被添加的（调查员提出），还是他们接触了某种放射性来源？
4. **摄影师底片**: 迪亚特洛夫的相机底片中有一张照片显示了一个"发光的物体" -- 但照片被当局没收，从未公开。
5. **直升机飞行员的证词**: 参与搜救的直升机飞行员后来声称他在现场看到了"橙色的光球"。
6. **相机**: 所有相机都回到了地面，底片中的内容有一部分被当局拿走。幸存的照片显示当晚天空中有异常亮度的物体。

## 档案缝隙

1. **原始法医报告**: 1959年完整法医报告只有约20页被公开。完整版（据说超过80页）从未解密。
2. **迪亚特洛夫日记最后一页**: 2月1日的日志只有一行字，然后是照片。照片内容未知。
3. **相机底片中的发光物体**: 多张底片被 confiscated，只有"不异常"的几张被允许发布。
4. **放射性来源**: 检测报告只记录了"发现放射性"，没有分析来源。
5. **尤里·尤丁的证词**: 唯一幸存者。他在1990年代接受采访时说"他们可能撞见了什么不该撞见的东西"，但之后保持沉默。
6. **目击者证词**: 离事发地50公里的另一个探险队声称在案发当晚看到了"天空中有橙色光球"。

## 游戏设计钩子

**玩家初始状态**: 你是1959年2月，斯维尔德洛夫斯克地区检察院的一名年轻调查员，被派往"死亡之山"协助调查。官方解释指向"雪崩 + 极端低温"，但你的上司对你说了四个字："档案不对劲。"

**第一决策点 (Turn 1)**: 在营地，你注意到帐篷里的物品摆放过于整齐 -- 不像是一次仓促逃跑。你面前的证据分成两条路:

**分叉方向**:
- 追踪衣物上的放射性来源 → 发现衣物被后处理过的痕迹，但无法确认由谁处理
- 检查直升机飞行员的目击记录 → 他提到了"橙色光球"，但他的报告中没有这个细节
- 走访50公里外的探险队 → 他们拒绝开口，有人监视他们
- 相信"雪崩说"并结案 → 开启一个看似平静但暗流涌动的后续

**Sigma 关键分歧**:
- 揭露放射性证据被人为篡改: +0.90 sigma (体制疑云)
- 揭示光球目击证词被压制: +1.20 sigma (冷战时空中异常)
- 发现探险队被人跟踪: +1.45 sigma (安全机构介入)
- 接受官方结论结案: +0.05 sigma

**后续线索**:
- 在河涧处发现的一块石头上有异常高热痕迹
- 相机底片中有一帧未公开的"发光物体"照片在档案室的微缩胶卷中可辨认
- 尤里·尤丁寄来一封匿名信，附有帐篷内的物品清单 -- 其中少了一件东西
