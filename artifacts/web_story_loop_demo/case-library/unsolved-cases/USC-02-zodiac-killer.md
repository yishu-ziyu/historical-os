# USC-02 黄道十二宫杀手 / Zodiac Killer

> 档案编号 SFPD-ZODIAC-1968
> 分类: 悬案 / 连环杀手
> 时间: 1968年12月20日 - 1969年10月11日（已知杀人期）
> 地点: 旧金山湾区，加利福尼亚州
> 疑犯身份: 至今未确认

---

## 案件概要

1968年末至1969年间，一名自称"黄道十二宫" (Zodiac) 的杀手在旧金山湾区活动。他杀害至少5人（7人受伤或死亡），并向多家报社寄送加密信件 -- 其中包含四套密码，声称信中藏有他的身份信息。

其中三套密码已被破解，但最著名的那一套 -- Z340 -- 直到2020年才被民间密码学家破译，但破译结果并未揭示凶手身份。2021年，FBI确认了破译，但杀人犯仍然自由（或已去世）。

他自称有34名受害者。没有人知道其余25人在哪里。

## 档案缝隙

1. **Z13 密码**: 仅13个字符，可能是杀人犯名字的缩写或全名 -- 至今未破解
2. **Z32 密码**: 据称包含"藏宝位置"或"下一个受害者信息"，至今未破解
3. **SFPD 日志**: 1969年7月4日接线员记录了来自 Zodiac 的第一次电话，但该录音在1990年代的档案迁移中"丢失"
4. **DNA 证据**: 从信封上提取了DNA，但未能匹配任何已知数据库
5. **Arthur Leigh Allen**: 唯一被警方长期怀疑的对象，死于1992年，从未被正式起诉。他的DNA与从信封上提取的不匹配 -- 但如果他戴了手套写信呢？
6. **FBI 的态度**: 2021年确认 Z340 破译后，FBI 拒绝公布破译内容是否包含身份信息

## 游戏设计钩子

**玩家初始状态**: 你是1969年8月，旧金山警局凶杀案组的一名新探员。刚刚被分配到 Zodiac 案件组。你面前的桌子上放着一封从 Chronicle 编辑部寄来的信，里面有 Z340 密码和一块沾血的三联布。

**第一决策点 (Turn 1)**: Z340 密码是 Killer 寄出的最后一封加密信。你面前有四种破解策略:

**分叉方向**:
- 与 FBI 密码分析部门合作 → 发现他们内部有分歧，部分人认为这不是一种"正规"密码
- 独立分析密码结构 → 发现其中包含方向性符号，可能指向藏身地点
- 联系 Vallejo 的目击者 → 他们描述的嫌疑人特征与警方画像严重不符
- 相信 Z408 的破译结果 -- 凶手自称"我为了取乐杀人" → 接受杀手是精神变态者的假设

**Sigma 关键分歧**:
- Z13 密码被破解（杀人犯名字）: +1.55 sigma (身份揭示)
- 发现 Z32 指向藏宝地点: +1.20 sigma (案件转折)
- 确认 Arthur Leigh Allen 是凶手（基于证据链）: +0.70 sigma
- 接受"杀手已死"的结论: +0.05 sigma

**后续线索**:
- 信中使用的邮票与当时市面上的品种有细微差异
- 血渍的血型在 FBI 数据库中找不到匹配
- 一名在 Vallejo 加油站工作的员工回忆起"那个男人有一次付钱时用的是法国硬币"
