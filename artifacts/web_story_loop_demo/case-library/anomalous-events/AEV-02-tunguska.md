# AEV-02 通古斯大爆炸 / Tunguska Event

> 档案编号 KGB-TUNGUSKA-1908
> 分类: 异常现象 / 大爆炸
> 时间: 1908年6月30日 UTC 7:17
> 地点: 俄罗斯西伯利亚，通古斯河附近，北纬 60.9°, 东经 101.9°
- 爆炸当量: 估计 10-15 兆吨（约等于一枚现代氢弹）
- 涉及面积: 约 2150 平方公里森林被夷平

---

## 案件概要

1908年6月30日早上7:17，一颗巨大的火球划过西伯利亚的天际，随后在西伯利亚的通古斯地区上空爆炸。爆炸威力相当于1000颗广岛原子弹。2150平方公里的森林被夷平 -- 面积相当于一个东京。

没有陨石坑。至今没有发现来自陨石的物理碎片。

在离爆炸中心30公里外的地方，一个观察者被热浪吹倒。600公里外的气压计记录到了冲击波。这次爆炸的能量释放连续三天在全球范围内造成了天空异常变亮的"白夜"现象。

在爆炸发生后的19年里，没有任何官方调查。苏联政府直到1927年才派出第一支科学考察队。

## 为什么没有陨石坑？

一个释放15兆吨TNT当量的爆炸，却没有留下任何撞击坑。这本身就说明了什么。

- 如果是一个固态小天体撞击地面，必然留下坑
- 如果是一个彗星或冰质天体，它会在大气层中爆炸
- 如果是一个小天体在5-10公里高空爆炸，它可以夷平2000平方公里而地面不留坑
- 这与2013年车里雅宾斯克事件（15米直径小天体在30公里高空爆炸）的模式高度吻合

但问题是：1908年没有卫星，没有全球气压网络，没有任何人"看到"进入大气层的物体。只有一个观察者说"他看到了火球划过天际" -- 而且他是事后才提供证词的。

---

## 苏联/俄罗斯蓝皮书

苏联调查分为三个阶段:

1. **Kulik 阶段 (1927-1938)**: 发现了"无坑"这一事实，但没有发现碎片。Kulik 在1942年死于战俘营（二战期间被德军俘虏）。
2. **蓝皮书阶段 (1940s-1960s)**: 发现了一些"微球粒" -- 直径小于1毫米的金属颗粒，含镍和铁。但它们的来源无法确认 -- 可能是陨石残留，也可能是本地土壤中的自然存在物。在这些微球粒中，有些样品含有异常的稀土元素比例。
3. **当代 (1990s至今)**: 主要假设为"冰彗星/小天体在大气层爆炸"。

## 档案缝隙

1. **Kulik 原始日记**: 他记录了什么 -- 部分记录在二战中丢失或被转移
2. **蓝皮书完整内容**: 苏联解体后部分解密，但仍有章节保持机密
3. **"微球粒"的完整分析**: 样品目前存放于俄罗斯科学院，部分样品对外声称"已丢失"
4. **格鲁吉亚/高加索的证词**: 爆炸当晚有报告称在高加索地区看到了"天空中出现红光" -- 这些报告是否被纳入调查 -- 不清楚
5. **1927年考察队的资金记录**: 谁批准了这次耗资巨大的考察，以及考察的目的 -- 部分记录缺失
6. **车里雅宾斯克事件前是否有内部评估**: 俄罗斯科学院是否有内部文件评估通古斯与车里雅宾斯克的相似性 -- 未公开

## 游戏设计钩子

**玩家初始状态**: 你是1927年春天，被派往通古斯地区的年轻地质学家。你的导师 Kulik 在出发前对你说了一句话："1890公里之外有一座城市，它叫克拉斯诺亚尔斯克。在那个城市里，有一些人在密切关注我们这次的发现。不要让我失望。"

**第一决策点 (Turn 1)**: 你到达了爆炸中心。森林被推平，但地面是完整的。没有坑。Kulik 开始进行航空勘测。你在地面上发现了一些不寻常的东西 -- 微球粒嵌在松树树脂中。你把它们装进了标本袋。你面前的路线:

**分叉方向**:
- 把标本交给 Kulik → 他会在考察报告中将它们标记为"陨石残留"
- 私下保留部分标本 → 后来发现它们的成分与已知的任何陨石类型都不匹配
- 写信给你的大学联系人说你发现了"异常矿物" → 信件被克格勃截获
- 研究本地曼西人的传说 → 他们称那座山为"死亡之山"，禁止任何人攀登

**Sigma 关键分歧**:
- 发现微球粒含有人工放射性同位素: +1.55 sigma (人工爆炸假设)
- 揭示蓝皮书中被隐藏的章节: +1.10 sigma
- 确认曼西人的禁忌与事件日期一致: +0.60 sigma
- 接受"冰彗星"解释并提交报告: +0.10 sigma

**后续线索**:
- 标本中的微球粒含有异常的铱-192（可能是人工来源）
- 克格勃对你的"来信"做出了反应，但不是以审查的方式 -- 而是以邀请的方式
- 当地一个曼西长老向你展示了一张古老的岩画 -- 一个圆形物体，从上方射下光芒
