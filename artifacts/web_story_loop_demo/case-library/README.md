## 档案材质说明

每个案件目录下包含：
- `README.md` — 案件概要、关键时间线、档案缝隙标记
- `materials/` — 真实档案引用、脱敏文件摘要、矛盾报告对比
- `narrative-hooks.md` — 游戏设计钩子（玩家决策点、sigma 值得分歧方向）
- `evidence-catalog.md` — 物证清单（影像/文件/信号/物证状态）
