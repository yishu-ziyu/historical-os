# COP-03 罗丝威尔事件 / 莫古尔计划 / Roswell Incident + Project Mogul

> 档案编号 AFH-Roswell-1947 / WAC-MOGUL-01
> 分类: 绝密行动 / 官方解释四次变更
> 时间: 1947年6月14日 - 至今
> 地点: 新墨西哥州罗斯威尔附近，Foster Ranch
> 密级: TOP SECRET — 1990年代部分解密

---

## 案件概要

1947年6月14日，牧场主 Mac Brazel 在罗斯威尔附近发现了一片奇怪的残骸 -- 由金属箔、橡胶条和木条组成的轻质碎片，上面有一些奇怪的符号。他报告给了当地警长，警长通知了附近的空军基地。

最初，基地的公共事务官 Jesse Marcel 向媒体宣布"我们找到了一个飞碟"。第二天，这条声明被撤回，改为"气象气球残骸"。

**在随后的47年间，美国官方对这个发现给出了四种不同的解释**:

1. **1947年（最初）**: "飞碟"
2. **1947年（次日）**: "坠毁的气象气球"
3. **1994年（国防部报告）**: "MoGol 高空监听项目的机密气球"
4. **1997年（官方纪念活动）**: "集成的雷达反射器和音效模拟器"

同一个残骸，四个官方版本。

---

## 四次官方解释的演变

### 第一次 (1947-07-08): "飞碟"
- Jesse Marcel 向 Roswell Daily Record 记者说："我们找到了一个飞碟。"
- 声明在24小时内被撤回。
- 所有原始照片（显示 Marcel 手持残骸）后来被标注为"被误导的公众信息"。

### 第二次 (1947-07-09): "气象气球"
- 军方向媒体展示了残骸，称其为来自怀特 Sands 导弹基地的气象气球。
- Marcel 说残骸是"普通橡胶条和金属箔" -- 但1980年代他亲口承认他看到的不是气象气球材料。

### 第三次 (1994): "Project Mogul"
- 国防部发布《空军对 UFO 相关报告的报告》，声称残骸来自一个名为 Project Mogul 的绝密监听项目。
- Project Mogul 使用了大量高压气球携带麦克风阵列到平流层，用于监听苏联核试验。
- 官方声称 Brazel 发现的残骸就是 Mogul 气球的一部分。
- 但反对者指出：Mogul 气球的组件与 Brazel 描述的符号不符。

### 第四次 (1997): "雷达反射器"
- 罗斯威尔50周年纪念活动中，美国空军再次修改说法，称残骸包含"雷达反射器和音效模拟器" -- 这是一套训练设备的一部分。
- 这个解释与前一个解释（Project Mogul）相互矛盾。

---

## Project Mogul 的背景

- **时间**: 1947年3月 - 1948年
- **机构**: 纽约大学 + Army Signal Corps
- **负责人**: Maurice Ewing (哥伦比亚大学) + James Peoples (NYU)
- **目的**: 在平流层部署麦克风阵列，侦听苏联核武器试验产生的次声波
- **气球设计**: 由橡胶气球和聚乙烯气球组成，共20-30层
- **问题**: Mogul 气球使用了大量聚乙烯胶带，而 Brazel 发现的残骸中包含了一种他从未见过的"几乎和纸一样薄"的金属箔

---

## 档案缝隙

1. **Mogul 第1号气球**: 1947年6月4日的 Mogul 飞行记录是否匹配 Brazel 发现残骸的时间 -- 存在争议
2. **Brazel 的描述**: 他最初说残骸上有"奇怪的符号" -- 这些符号从未被官方解释为 Mogul 部件上的标记
3. **Jesse Marcel 的原始声明录音**: 声称已"在档案迁移中丢失"
4. **飞机残骸**: 一些目击者声称看到"除了气球碎片之外还有金属碎片和某种织物"
5. **外星人"尸检"**: 1947年医院记录声称有"非人类遗体"被运送到附近基地 -- 医院在1950年代进行了翻修，部分档案被毁
6. **四项官方声明之间为何矛盾**: 没有内部分析解释了为什么解释在四次之间发生了变化

## 游戏设计钩子

**玩家初始状态**: 你是1947年7月9日，罗斯威尔陆军航空基地的公共事务部文员。今天你收到了三份文件 -- 第一份是6月14日 Brazel 的报告（仍在处理中），第二份是 Jesse Marcel 的"飞碟声明"草稿（已被命令撤回），第三份是来自华盛顿的电报 -- 要求你"彻底处理所有6月14日以来的文档"。

**第一决策点 (Turn 1)**: 三份文件之间的时间差暴露了一个矛盾：Washington 的指令到达时间比 Roswell 的原始报告还早12小时。这意味着有人在事件被公开之前就已经决定要"处理"它。

**分叉方向**:
- 按指令处理所有文件 → 你将永远不知道 Brazel 发现的到底是什么
- 偷偷保存一份 Brazel 报告的副本 → 触发 FBI 的内部调查
- 调查 Moscow 电报的来源 → 发现 Signal Corps 有一个你不知道的项目
- 联系 Jesse Marcel → 他的证词与你手中的文件形成第三套解释

**Sigma 关键分歧**:
- 揭示 Washington 在事件公开前 12 小时已下令掩盖: +1.20 sigma
- 发现 Project Mogul 与残骸实际不符: +1.10 sigma (官方解释的裂痕)
- 将 Brazel 发现的残骸与已知的 Mogul 材料对比: +0.45 sigma
- 接受官方"气象气球"结论: +0.05 sigma

**后续线索**:
- Brazel 报告中描述的"符号"与任何已知的 Mogul 部件编号都不匹配
- 1947年6月4日的 Mogul 飞行记录中有一个"载荷未回收"的条目
- 一份来自 Signal Corps 的未公开备忘录，提到"非标准观测结果"
