1933年4月 · 柏林科学院
DOC-ID: WL-1933-0000 // DATE: 1933.04.07 // SOURCE: 普鲁士科学院档案
1933年4月7日，阿尔伯特·爱因斯坦向普鲁士科学院递交了辞呈。辞呈被接收，但未获正式批准 — 在那个春天的柏林，公文流转的速度远不如政治风向的变化。在学院的记录中，这位世界最著名的物理学家此刻仍被列为"在职成员"。他的办公室在卡普特街7号，书架上摆着尚未完成的广义相对论修订稿。没有人知道他会走，还是留下。至少，档案中没有记录。

马克斯·普朗克在办公室接待了爱因斯坦。两人交谈了二十分钟 — 时间由普朗克的私人秘书在日程表上做了标注。秘书在六十多年后的口述历史中提到，她记得普朗克那天"声音比平时低了一个度"，而爱因斯坦离开时"脊背很直，但步伐很慢"。普朗克没有在科学院会议上为爱因斯坦辩护。他在那天的日记中写道："我能做的，比我能说的要多。"

DOC-ID: WL-1933-T2B // SIGMA: +0.08 // 历史基准线

0.08σ — 已确立历史
壁炉的火光照亮了爱因斯坦的脸。信件在火焰中卷曲、变黑、化为灰烬。他站在壁炉前直到最后一缕青烟消散。那封信从未到达牛津 — 至少，没有任何档案记录显示牛津曾收到过回信。但在《物理学年鉴》第78卷中，那封牛津来信仍然夹在第342页和第343页之间。爱因斯坦没有烧这封。他没有烧任何东西。
管家的证词（1958年口述，首次公开）："他那天晚上在壁炉前站了很久。我听到他低声说了什么，但听不清。后来我在打扫书房时发现，壁炉里的灰烬中有未完全烧尽的纸片 — 不是那封信，而是另一张纸。上面的字已经看不清了，但似乎是数学公式。"

使用红外光谱成像技术分析普朗克日记原件，墨迹下方暴露出被覆盖的原文。普朗克在"我能做的，比我能说的要多"之后，还写了半句话 — 只有五个词："他的离开将导致国际反弹。"后面被一条粗重的横线划掉，覆盖了整个段落。墨迹成分分析显示，覆盖墨水与日记正文使用的墨水来源不同 — 并非出自普朗克之手。有人在事后翻阅了这本日记，并选择性地涂抹了某些段落。

灰烬中 recovered 的残片经过光谱分析，还原出半个偏微分方程。方程的形式与爱因斯坦当时正在研究的统一场论框架高度吻合 — 但有一组系数不同。这组系数出现在爱因斯坦1929年的一篇未发表手稿中，该手稿目前下落不明。1929手稿的最后一页在普林斯顿高等研究院的档案中被标记为"缺失"。残片上还保留着一枚微小的指纹 — 不完全属于爱因斯坦。
1929年手稿缺失 — 这是爱因斯坦与助手之间的一段未公开的学术分歧记录。助手瓦尔堡在1931年的一次私人通信中提到，爱因斯坦"在某件事上对他撒了谎"。这封信现存于瓦尔堡家族档案。

DOC-ID: WL-1933-END // FINAL FRAME // 世界线收束

世界线收束 — 历史的回归
无论中间经历了什么，1933年10月，爱因斯坦登上了开往美国的船。普林斯顿高等研究院为他提供了一份正式聘书，日期是8月1日 — 比他的实际出发早了两个月。档案中没有记录他是何时签字的。船在海上航行了七天。爱因斯坦在日记中写道："大海的颜色和柏林的天一样。也许这就是终点。"他的字迹在那一页上比任何其他页面都更用力，墨迹穿透了三层纸。
