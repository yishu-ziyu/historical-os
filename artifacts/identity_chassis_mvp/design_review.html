方案 B · 舞台灯（单栏 · 戏 → 情景动作）

推荐默认 注意力最可控 改动成本中 适合文字 Agent

方案 C 批注

优点 天然解决「动作和场面脱节」：动作永远挂在物件上。更接近你说的「要有交互体感」。
风险 多一步点击；开放身份时要生成热区列表，底盘更重；美术/占位不好会像简陋点选冒险。

方案 D · 书页叙事 + 底栏选择

最像读书 改动成本低 空间感弱 易显「点链接小说」

整页就是一段散文，选择像脚注一样列在段落后。注意力路径极短：往下读 → 点句。 适合强文笔；弱在「世界在周围」的体感，开放沙盒感会淡一些。

方案 D 批注

何时选 D 你更在意「一晚上读完一段人生」而不是「在空间里搅和」。文笔必须过硬，否则像廉价分支小说。
与 AI for fun 沙盒 世界自转、多身份底盘都能做，但玩家感知会偏「章节」而非「活在城里」。要强沙盒，B/C 更贴。
